# Dashboard Brasileirão

## Descrição
Projeto de análise exploratória de dados do Campeonato Brasileiro,
desenvolvido com Python, Pandas, Streamlit e Plotly.

## Funcionalidades
- Indicadores gerais dos clubes
- Filtros por temporada e clube
- Comparação de vitórias, derrotas e empates
- Análise do saldo de gols
- Visualização do valor dos elencos
- Análise da idade média dos jogadores
- Tabela de classificação
- Exportação dos dados filtrados

## Tecnologias
- Python
- Pandas
- Streamlit
- Plotly

## Como executar
1. Instale as dependências:
   python -m pip install -r requisitos.txt

2. Execute o dashboard:
   python -m streamlit run 01_Times.py
